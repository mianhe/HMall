## 二、主流程边界与极端情况覆盖度

以下仅考虑**主流程上的边界与极端情况**（不含删除/编辑等扩展功能）。

### 类目（Category）

| 类型 | 场景 | 需求是否列出 | .feature 是否覆盖 | 建议 |
|------|------|--------------|-------------------|------|
| 边界 | 父类目不存在时创建子类目应失败 | 否 | 否 | **建议补充**（领域不变式：父须已存在） |
| 边界 | 查询不存在的父类目下的子类目（返回空或 404） | 否 | 否 | 可选（返回空列表即满足主流程） |

### 商品（Product）

| 类型 | 场景 | 需求是否列出 | .feature 是否覆盖 | 建议 |
|------|------|--------------|-------------------|------|
| 边界 | 类目 ID 不存在时创建商品应失败（404） | 否 | 否 | **建议补充** |
| 边界 | 按 ID 查商品详情时 ID 不存在应返回 404 | 否 | 否 | **建议补充** |
| 边界 | 按类目查商品时类目不存在（返回空或 404） | 否 | 否 | 可选 |

### 规格维度与选项（Spec-dimension）

| 类型 | 场景 | 需求是否列出 | .feature 是否覆盖 | 建议 |
|------|------|--------------|-------------------|------|
| 边界 | 同 SPU 内维度名称重复应失败 | 否 | 否 | **建议补充**（领域：同 SPU 内唯一） |
| 边界 | 为不存在的维度添加选项应失败（404） | 否 | 否 | **建议补充** |
| 边界 | 同维度内选项值重复应失败 | 否 | 否 | **建议补充**（领域：同维度内唯一） |
| 边界 | 查询不存在的 SPU 的维度及选项应 404 | 否 | 否 | 可选 |

### SKU

| 类型 | 场景 | 需求是否列出 | .feature 是否覆盖 | 建议 |
|------|------|--------------|-------------------|------|
| 边界 | 创建 SKU 时传入不属于该 SPU 的 Option 应失败 | 4.3 已含「Option 不属于该 SPU」 | 4.3 仅覆盖「未选齐」 | **建议补充**：单独场景「Option 属其他 SPU 应失败」 |
| 边界 | 价格非法（如负数）应失败 | 否 | 否 | **建议补充**（领域：价格≥0） |
| 边界 | 按 SPU+SKU 查详情时 SKU 不存在或不属于该 SPU 应 404 | 否 | 否 | **建议补充** |
| 边界 | 按 SPU 查 SKU 列表时 SPU 不存在（返回空或 404） | 否 | 否 | 可选 |

## 三、已补充的边界场景（需求 + .feature 已同步）

以下边界与极端情况已在需求文档与对应 .feature 中补充，并保持一一对应：

1. **类目**：1.5 父类目不存在时创建子类目应失败（如 404）。
2. **商品**：2.6 类目 ID 不存在时创建商品应失败；2.7 按 ID 查商品详情时商品不存在应返回 404。
3. **规格维度与选项**：3.7 同 SPU 内维度名称重复应失败；3.8 同维度内选项值重复应失败；3.9 为不存在的维度添加选项应失败（如 404）。
4. **SKU**：4.6 创建 SKU 时传入不属于该 SPU 的 Option 应失败；4.7 创建 SKU 时价格为负数应失败；4.8 按 SPU+SKU 查详情时 SKU 不存在或不属于该 SPU 应返回 404。
