## Feature 1：券模板管理

管理员创建、编辑、查询和停用优惠券模板。

### 场景

| # | 场景 | 优先级 |
|---|------|--------|
| 1.1 | 创建满减券模板（指定门槛金额、优惠金额、总量、有效期、每人限领） | P0 |
| 1.2 | 创建折扣券模板（指定折扣率、最高优惠上限、总量、有效期、每人限领） | P0 |
| 1.3 | 查询券模板列表（分页） | P0 |
| 1.4 | 查询单个券模板详情 | P0 |
| 1.5 | 停用券模板（status → INACTIVE，停止发放） | P0 |
| 1.6 | 创建模板时必填字段缺失返回 400 | P1 |
| 1.7 | 创建模板时门槛金额或优惠金额为负数返回 400 | P1 |
| 1.8 | 创建折扣券时折扣率不在 (0, 1) 范围返回 400 | P1 |
| 1.9 | 停用不存在的模板返回 404 | P1 |

### 场景

| # | 场景 | 优先级 |

| 2.3 | 查询用户的优惠券列表 | P0 |
| 2.4 | 按状态筛选查询用户的优惠券 | P1 |
| 2.5 | 查询可领券模板列表（排除已停用、已领满、库存不足的模板） | P0 |
| 2.6 | 领券时模板已停用返回 400 | P1 |
| 2.7 | 领券超过每人限领数量返回 400 | P1 |
| 2.8 | 库存不足时领券返回 400 | P1 |
| 2.9 | 过期优惠券自动失效 | P0 |

## Feature 4：统一价格引擎（活动 + 券）

Promotion 对外提供统一算价能力：先计算活动优惠，再叠加优惠券优惠，输出行级折扣明细与实付金额。

### 场景

| # | 场景 | 优先级 |
|---|------|--------|
| 4.1 | 单品活动命中时返回活动优惠与活动价 | P0 |
| 4.2 | 订单满减活动命中时返回活动优惠 | P0 |
| 4.3 | 同互斥组多个活动命中时仅最优活动生效 | P0 |
| 4.4 | 不同互斥组活动可叠加 | P0 |
| 4.5 | 活动 + 券同时命中时返回分项优惠（activity/coupon）与正确实付 | P0 |
| 4.6 | 查询可用券时使用“活动后金额”作为门槛判断基数 | P1 |
| 4.7 | 批量预估 SKU 活动价（列表/详情页展示） | P0 |

## Feature 5：用户定向与满件折扣（来自业务需求 [用户定向与满件折扣](../../business-requirements/promotion-theme/user-targeting/overview.md)）

统一价格引擎扩展：在活动/券命中判定中引入用户分群（标签/等级），并支持满件折扣规则；Order 事件可回溯优惠快照。

### 场景

| # | 场景 | 优先级 |
|---|------|--------|
| 5.1 | 创建定向活动（配置等级/标签命中条件） | P0 |
| 5.2 | 命中定向用户时活动生效，不命中用户自动排除该活动 | P0 |
| 5.3 | 创建满件折扣活动（按件数门槛触发） | P0 |
| 5.4 | 满件门槛边界（N-1/N/N+1）计算正确 | P0 |
| 5.5 | 定向活动 + 满件活动 + 券叠加时返回正确分项优惠与实付 | P0 |
| 5.6 | calculate-price 返回可解释信息（couponId、pricingSnapshot、可选不命中原因） | P1 |

## Feature 6：消费用户分群实时结果（来自业务需求 [用户分群与圈选](../../business-requirements/user-management-theme/user-segmentation/overview.md)）

Promotion 持续作为用户分群结果消费者，确保用户等级/标签更新后定向命中实时变化。

### 场景

| # | 场景 | 优先级 |
|---|------|--------|
| 6.1 | 用户等级更新后，相同定向活动的命中结果即时变化 | P0 |
| 6.2 | 用户标签更新后，活动命中与不命中原因即时变化 | P0 |
| 6.3 | User 查询失败时算价走可解释降级（默认分群 + 提示） | P1 |
